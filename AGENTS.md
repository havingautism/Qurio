## Design Context

### Users
Qurio is optimized consumer-first: individual users who need to run serious AI-assisted work, not just chat. They are typically handling multi-step tasks (research, tool use, synthesis, and execution) and need one workspace that stays organized as complexity grows.

The primary job-to-be-done is to maintain calm control while orchestrating agents, tools, documents, and evidence in one flow.

### Brand Personality
Core personality: Calm, Intelligent, Fluid.

Voice and tone should feel composed, capable, and precise. The interface should communicate confidence without aggressiveness and stay focused on helping users feel in control of complex workflows.

Target emotional outcome: Calm Control.

### Aesthetic Direction
Visual direction: fluid glass UI language as a core motif, with smooth transitions and layered surfaces that preserve readability and hierarchy.

Reference products:
- Linear: crisp hierarchy, focus, efficient interaction density.
- Notion: calm composition, clear structure, approachable minimalism.

Anti-references:
- Gemini-style and GPT-style default chat aesthetics should be avoided; Qurio should not look like a generic assistant shell.

Theme direction:
- Support light and dark/system modes with a fluid, glass-forward presentation.
- Preserve strong legibility and contrast in both themes.

Accessibility target:
- WCAG AA baseline for product decisions and UI implementation.

### Design Principles
1. Calm Control First: every screen should reduce cognitive load and help users feel oriented, in-command, and never rushed.
2. Intelligence Through Clarity: prioritize clear information hierarchy, explicit state, and grounded outputs over decorative complexity.
3. Fluid Interaction Model: motion and transitions should feel continuous and purposeful, never distracting; interaction should feel smooth across contexts.
4. Glass With Discipline: use glassmorphism as a structural layer system, but never at the expense of contrast, readability, or task focus.
5. Consumer-Grade Approachability, Pro-Grade Capability: keep advanced workflows accessible to individual users through clean defaults and progressive disclosure.
