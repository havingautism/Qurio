惰性过期：只有当访问⼀个key时，才会判断该key是否已过期，过期则清除。该策略可以最⼤化地

(expires字典会保存所有设置了过期时间的key的过期时间数据，其中，key是指向键空间中的某个键的

Redis中同时使⽤了惰性过期和定期过期两种过期策略。
